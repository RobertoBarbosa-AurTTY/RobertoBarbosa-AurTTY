## 🏢 What I do at Carajás

Backend services in **TypeScript (Node.js / Bun)** that run critical retail operations every day:

- 🛒 **E-commerce & marketplace integrations** — order, catalog and image sync with **VTEX** and **AnyMarket**
- 🧾 **Fiscal documents** — NF-e / DF-e retrieval and reprocessing with **SEFAZ** (XML, digital signatures, SOAP)
- ⏱️ **Scheduled jobs & data pipelines** — batch processing, overlap protection, retries and structured job logging
- 🔌 **REST APIs** — validated with **Zod**, documented with **OpenAPI / Swagger**
- 🗄️ **Data** — **MySQL**, **Oracle** and **Redis** via Sequelize, file storage on **AWS S3**
- 📈 **Observability & reliability** — error handling at the call site, logs persisted to the database, memory profiling of long-running processes, monitoring/ticketing integrations

## 🤖 AI-assisted engineering

I use AI as a **force multiplier, not a shortcut**: every change is still reviewed, tested and understood.

- **Claude Code** as daily pair programmer — planning, refactoring, code review and debugging production issues
- **Custom agents, skills and slash commands** — e.g. log triage that groups production errors and separates real bugs from noise, and AI-written commit messages generated from the diff
- **Persistent agent memory** in Obsidian (session logs, handoffs, project maps) so context survives between sessions
- **MCP & tool integrations** connecting agents to logs (Dozzle), metrics (Grafana) and the codebase
